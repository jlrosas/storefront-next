**Pregunta para el oferente:** ¿Puede entender quién es el cliente, qué está intentando resolver hoy y cambiar de forma visible la experiencia para hacerlo sentir reconocido, relevante y acompañado?

Una misma marca, una misma plataforma, experiencias diferentes. "De: 'Aquí está nuestro menú. Elige.' A: 'Entiendo qué necesitas. Déjame ayudarte a resolverlo.'" Debe sentirse en lo que ven, el orden, lo que no necesitan ver, cómo les hablamos, qué producto recomendamos, qué beneficio mostramos y cuántos pasos necesitan para comprar.

## Sofía · Heavy user — "Compro siempre acá. ¿Por qué tengo que empezar de cero cada vez?"
- Entrada: identificarla desde App, Web, CRM o campaña; "Hola Sofía".
- Home: Repetir último pedido → Favoritos → Papa Puntos → Beneficios → Recomendaciones. Sin 50% genérico dominando.
- Exploración: orden por historial, afinidad, horario, modalidad; promos en segundo plano.
- Carrito/checkout: dirección habitual, tienda, preferencias, Papa Puntos, beneficios, cross-sell relevante, medio de pago preferido.
- Post compra: historial → preferencias → puntos → frecuencia → próxima mejor acción.
- Resumen: Banner loyalty/novedad · Home repetir, favoritos, puntos y saldo · Menú afines primero · Promos menos agresivas · CTA recompra.

## Diego · Switcher — "Tengo muchas opciones. ¿Por qué debería pedir Papa Johns?"
- Entrada: mantener la promesa del anuncio (Meta, Google, CRM, deep link). Si hizo clic en "2 pizzas por $X", no cae en un home genérico.
- Home: ocasiones y tamaño de grupo: Para 2 → Para 3 → Para 4 → Almuerzo → Partido → Celebración → Bajón.
- Exploración: promos arriba, luego Más vendidos, Recomendados, precio/cantidad.
- Carrito: "Por $1.500 más agrega bebida", "Te faltan $X para…", "Completa tu combo".
- Post compra: CRM → Papa Puntos → recompra; moverlo hacia Heavy.
- Resumen: Banner promo potente · Home ocasiones · Promos más agresivas · CTA "esto te conviene ahora". "No se trata de mostrar más promociones, sino de seleccionar cuál según contexto, propensión y comportamiento."

## Valentina · Non buyer / lapsed (2 años sin comprar) — "¿Por qué debería volver si antes dejé de elegirlos?"
- Entrada: "Queremos que vuelvas a disfrutar Papa Johns", sin mensajes invasivos.
- Home: promos, best sellers, novedades, beneficios del canal propio, Delivery/Pick Up; aquí sí promo agresiva de reactivación.
- Exploración: reducir incertidumbre (tamaño, cantidad, ingredientes, precio, para cuántos); etiquetas "Más pedido", "Ideal para 2", "Novedad".
- Entrega: Delivery, Pick Up o comedor, con costos, tiempos y condiciones por adelantado, sin borrar el pedido.
- Checkout: invitada, sin sorpresas, solo datos indispensables.
- Post compra: cumplir, comunicar estado, resolver incidencias, feedback, activar loyalty.
- Resumen: "Una experiencia de descubrimiento, confianza y conversión; no una home excesivamente personalizada."

## Otros puntos del kit relevantes para la demo de perfiles
- KPIs: CVR 25% (Web 18%, App 30%), bounce < 30%, cross-selling 35% de pedidos, base identificada > 70%, uplift de personalización +5%, > 2 A/B tests/mes, carga < 2,5 s.
- Ecosistema: CRM es Synerise (se queda); Aloha/NCR, DispatchTrack, Zendesk.
- Cada capacidad debe marcarse como estándar, configuración, integración, desarrollo o roadmap.
